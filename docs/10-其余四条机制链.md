# 其余四条机制链 —— 公式还原

> 数据来源：`libil2cpp_p3.so` IFix fallback 反汇编
> 符号表：`work/_x_map3.pkl`（VA2G 325,832 / MN 388,066 / TD 47,503）

---

## 0. 核心发现：统一的 `GetPercentParam` 模式

**四条链全部走同一个函数**：

```c
float GetPercentParam(object* self, float default_value, int slot);
// @ 0x068BED28
```

**调用方只需提供「默认值 + 槽位」**：

| 机制 | 调用者 | 默认值 | 槽位 |
|---|---|---|---|
| **攻击速度** | `GetSelfAttackSpeedFactor` @ `0x068BD544` | **30.0** | `0xE` (14) |
| **移动速度** | `GetSelfMoveSpeedFactor` @ `0x068BDABC` | **15.0** | `0xF` (15) |
| **冷却缩减** | `SkillHasteUsesDiminishingCooldownFormula` | 0.05 / 0.02 | 8 / 3 |

**⟹ 意义**：游戏把「角色自身属性」抽象成**参数槽位**，天赋/装备只能改这些槽的值。
默认值就是「没有任何加成时的基础系数」。

## 1. ★★★ 冷却缩减（技能急速）

### 1.1 核心函数

```
SkillHasteUsesDiminishingCooldownFormula @ 0x075F6FA4
UsesSkillHasteCooldown                    @ 0x07FC1930
ExistingAdditiveRateAndSkillHasteRemainEffective @ 0x075FA218
ApplyCooldownReductionTalentDelta         @ 0x06926DD4
ResolveCooldownReductionLoss              @ 0x0692C538
ResolveCooldownReductionBonus             @ 0x0692CCD8 / 0x0692CFAC
GetSkillHaste                             @ 0x079A23D8
SetSkillCooldown                          @ 0x065AC598
StartCooldown                             @ 0x06870848
```

### 1.2 ★ 参数初始化（`ExistingAdditiveRateAndSkillHasteRemainEffective` fb `0x075FA290`）

```asm
0x075FA290  adrp x8, #0xfe4f000
0x075FA294  ldr  x8, [x8, #0x390]        ; 取类实例
0x075FA2A8  bl   #0x6c896fc               ; .ctor
0x075FA2B0  adrp x8, #0x2cc1000
0x075FA2B4  ldr  s0, [x8, #0x6e8]        ; ★ 常量 0x2CC16E8 = 0.05
0x075FA2B8  mov  w1, #8                  ; ★ 槽位 8
0x075FA2C4  bl   #0x6c8b568               ; SetBaseValue(obj, 8, 0.05)

0x075FA2C8  adrp x8, #0x2cc1000
0x075FA2CC  ldr  s0, [x8, #0x6ec]        ; ★ 常量 0x2CC16EC = 0.02
0x075FA2D0  mov  w1, #3                  ; ★ 槽位 3
0x075FA2DC  bl   #0x6c8b568               ; SetBaseValue(obj, 3, 0.02)

0x075FA2E0  fmov s0, wzr                 ; 0.0
0x075FA2E4  mov  w1, #5                  ; ★ 槽位 5
0x075FA2F0  bl   #0x6c8b568               ; SetBaseValue(obj, 5, 0.0)
```

### 1.3 常量值（实测）

| 地址 | 值 | 用途 |
|---|---|---|
| `0x2CC16E8` | **0.05** | 槽位 8 基准 |
| `0x2CC16EC` | **0.02** | 槽位 3 基准 |
| `0x2CC16F0` | 65535.0 | 钳位上界 |
| `0x2CC16E4` | 1.055 | 邻近 |
| `0x2CC16E0` | 0.949237 | 邻近 |

### 1.4 判定逻辑

```asm
; UsesSkillHasteCooldown fb 0x07FC1968
0x07FC1968  sub  w8, w19, #1
0x07FC196C  cmp  w8, #2
0x07FC1970  cset w0, lo              ; 返回 (type-1) < 2  ? 1 : 0
0x07FC1978  ret
```

**⟹ 只有 `type ∈ {1, 2, 3}` 时才使用技能急速公式**（其余走普通冷却）。

### 1.5 关键结论

- **技能急速用「递减公式」**（函数名直接写明 `Diminishing`）
- 基础系数：槽位 8 = `0.05`，槽位 3 = `0.02`
- 只有特定 type 的技能才吃技能急速

## 2. ★★★ 移动速度

### 2.1 核心函数

```
ResolveMoveSpeed                     @ 0x06367A20 / 0x0646A0B0
ResolveIdleMoveSpeed                 @ 0x0646B4C8
ResolveMoveSpeedBonus                @ 0x0692CBDC  → fb 0x0692CC1C
ResolveMoveSpeedLoss                 @ 0x0692C808  → fb 0x0692C848
GetSelfMoveSpeedFactor               @ 0x068BDABC  → fb 0x068BDAF4
AddMoveSpeedPercent                  @ 0x069DA1A4  → fb 0x069DA1DC
ApplyMoveSpeedDown                   @ 0x068BB720
FreeFollowIdleMoveUsesHalfSpeed      @ 0x075FBAA8
FreeFollowChaseMoveUsesFullSpeed     @ 0x075FBB0C
ResolveMecha2MoveSpeedMultiplier     @ 0x06C67CE8
```

### 2.2 ★ `AddMoveSpeedPercent` —— **直接返回 20**

```asm
; fb 0x069DA1DC
0x069DA1DC  mov  w0, #0x14            ; ★ 0x14 = 20
0x069DA1E0  ldp  x30, x19, [sp], #0x10
0x069DA1E4  ret
```

**⟹ 移速加成返回值为整数 20**（可能是「20%」的原始值）。

### 2.3 ★ `GetSelfMoveSpeedFactor` —— 默认 15.0，槽位 15

```asm
; fb 0x068BDAF4
0x068BDAF4  fmov s0, #15.00000000     ; ★ 默认值 15.0
0x068BDAF8  mov  w1, #0xf             ; ★ 槽位 15
0x068BDAFC  mov  x0, x19
0x068BDB04  b    #0x68bed28           ; → GetPercentParam
```

### 2.4 `ResolveMoveSpeedBonus` —— 默认 0.3

```asm
; fb 0x0692CC1C
0x0692CC24  bl   #0x692a638           ; TryGetConfig
0x0692CC30  ldr  x1, [sp, #8]
0x0692CC34  ldr  s0, [x8, #0xcac]     ; ★ 0x2CC1CAC = 0.3
0x0692CC40  bl   #0x692a76c           ; ParsePositiveParam
0x0692CC48  ldr  s0, [x8, #0xcac]     ; 配置缺失时也用 0.3
```

**默认加成 = 0.3**，且 `ParsePositiveParam` 会**保证非负**。

### 2.5 `ResolveMoveSpeedLoss` —— 默认值在 `0x2CC1024`

```asm
0x0692C860  ldr  s0, [x8, #0x24]      ; = 0x2CC1000 + 0x24 = 0x2CC1024
0x0692C86C  bl   #0x692a76c           ; ParsePositiveParam
```

| 地址 | 值 |
|---|---|
| `0x2CC1024` | **0.15** |
| `0x2CC1CAC` | **0.3** |

### 2.6 关键结论

- **移速是三段式**：`基础 × (1 + Bonus - Loss) × 因子`
- `Bonus` 默认 0.3，`Loss` 默认 0.15
- `GetSelfMoveSpeedFactor` 默认 15.0（槽位 15）

## 3. ★★★ 攻击速度

### 3.1 核心函数


### 3.2 ★ `GetSelfAttackSpeedFactor` —— **默认 30.0，槽位 14**

```asm
; fb 0x068BD57C（之前实测）
fmov s0, #30.00000000          ; ★ 默认值 30.0
mov  w1, #0xe                  ; ★ 槽位 14
b    #0x68bed28                ; → GetPercentParam
```

### 3.3 `ResolveWeaponSpeed` —— 只有下限钳位

```asm
; 之前实测 @ 0x0635C100（IFix patch 0x2e67）
ResolveWeaponLevel → GetSpeed → fmax s0, s0, #0
```

**⟹ 只有下限 `max(speed, 0)`，没有上限钳位。**

> wiki 说的「10% / 1000% 钳位」**不在这个函数里** —— 在上层调用方。

### 3.4 关键结论

- 角色自身攻速因子默认 **30.0**（槽位 14）
- `ResolveWeaponSpeed` 只做 `max(x, 0)`
- wiki 的钳位说法需在**上层**验证

## 5. 四条链的统一结论

### 5.1 核心抽象：参数槽位表

| 槽位 | 用途 | 默认值 | 读取函数 |
|---|---|---|---|
| **3** | 冷却（副） | 0.02 | `SetBaseValue` |
| **5** | 冷却（备用） | 0.0 | `SetBaseValue` |
| **8** | 冷却（主） | 0.05 | `SetBaseValue` |
| **14** | 自身攻速因子 | 30.0 | `GetPercentParam` |
| **15** | 自身移速因子 | 15.0 | `GetPercentParam` |

### 5.2 三条链的默认值对比

| 链 | 默认值 | 含义 |
|---|---|---|
| 攻速 | 30.0 | 更高 —— 攻速是主要输出属性 |
| 移速 | 15.0 | 中等 |
| 冷却 | 0.05 / 0.02 | 更小 —— 冷却基数小，加成更敏感 |

### 5.3 与 wiki 的差异

| 项 | wiki 说法 | 逆向结果 |
|---|---|---|
| 冷却 | 「减少技能冷却时间」 | ✅ 有**递减公式**（`Diminishing`），非线性 |
| 冷却适用范围 | 未细分 | ⚠️ **仅 type 1/2/3 的技能**吃技能急速 |
| 移速 | 三段式公式 | ✅ 一致（`Bonus` 0.3 / `Loss` 0.15） |
| 攻速 | 「攻速加快」 | ✅ 默认 30.0，且 `ResolveWeaponSpeed` 只有下限 |
| 护甲 | 「护甲回复速度」 | ✅ 但额外发现**概率型回复** |
