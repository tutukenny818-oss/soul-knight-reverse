# 暴击：简单版

> 你问的两件事：**「累加累乘太复杂」**和**「暴击在哪」**。
> 这篇用大白话重讲，把之前那份技术文档全部简化掉。

---

## 一、先回答：暴击在哪？

### 一句话

**暴击不在"伤害公式"里，它在"伤害公式之前"。**

游戏里有两套东西：
- **暴击率** → 决定「这次打不打得出暴击」（掷骰子）
- **暴击倍率** → 决定「打出暴击后伤害乘几」（乘上一个数）

**这两件事是分开的，而且都在最终伤害公式之前就定好了。**

### 代码里的位置

| 环节 | 函数 | 干什么 |
|---|---|---|
| ① 掷骰子 | `RollCritical` | 按暴击率判定，返回 true/false |
| ② 取倍率 | `GetCriticDamageFactor` | 去**数据表**里读倍率值 |
| ③ 改伤害 | `ApplyCriticalResultDamageModifier` | 用它乘一次伤害 |
| ④ 取整 | `CalculateFinalDamage` | 最后统一取整 |

**关键在②**：我反汇编了 `CalculateCriticalDamage`（`0x06479754`），

```asm
0x64797F4  bl   #0x6c8be0c      ; GetValue(对象)  ← 从数据对象读值
0x64797FC  fcmp s0, #0.0
0x6479804  b.le #0x647982c      ; 值 ≤0 → 返回 0.0
0x6479828  fmov s0, #1.00000000 ; ★ 没数据时返回 1.0
```

**里面没有任何 `2.0` 或 `200` 这样的常数。**

**⟹ 结论：200% 这个数不是写死在代码里的，是每个武器/每种攻击各自配置的值。**

这跟 wiki 的说法其实是一致的 —— wiki 说「**通常**为 200%」，用了"通常"两个字，正是因为它是**逐武器配置的**，不是全局固定。

### 那 200% 存在哪？

在**配置表**里。我已经找到相关字段：

| 表 | 字段 | 含义 |
|---|---|---|
| `weapons_game.csv`（1683 条） | `crit_max` | **暴击率**（0/5/10/20/25/30/50…） |
| 同上 | `dmgMultiFactor` | 伤害倍率（1080 个是 1.0，1 个是 15.0） |

> ⚠️ 注意：`dmgMultiFactor` **不是**暴击倍率，它是武器自己的伤害系数。
> 真正的暴击倍率在**未解密的 `luban.bytes`** 里（那是一张加密表）。

## 二、再回答：累加累乘，其实就一句话

之前那篇讲得太绕。**核心只有一句话**：

> **同一类加成先加在一起，不同类之间再相乘。**

### 举个例子

假设你有：
- 天赋 A：伤害 +20%
- 天赋 B：伤害 +30%（和 A 同类）
- 天赋 C：暴击伤害 +50%（和 A 不同类）

**算法**：
```
第一步（同类相加）：20% + 30% = 50%
第二步（转成倍率）：1 + 50% = 1.5
第三步（不同类相乘）：1.5 × 1.5 = 2.25
```

**就这么简单。**

### 我在代码里看到的

代码里**没有**"把所有天赋循环加一遍"的循环。

每个加成类别对应**一个函数**，调用它就直接返回这类加成的**总倍率**：

```asm
; AddAttackPercent
ldr   s0, [x8, #0x6ec]     ; 读一个系数
scvtf s1, w19              ; 等级转浮点
fmul  s1, s1, s0           ; 等级 × 系数
fadd  s0, s1, s0           ; 加上基线
ret                        ; 返回总倍率
```

**⟹ 所以"同类相加"是在这个函数内部算好的，调用方拿到就是总倍率，直接相乘就行。**

这也解释了 wiki 说的「**取整情况较为混乱**」—— 因为**每个函数内部都有取整**，不是统一到最后取。

## 三、和 wiki 的差异（只有 2 条重要）

之前列了 10 条，其实**真正重要的只有 2 条**：

### ① 取整方式：wiki 写错了（但只差 1 点伤害）

| | |
|---|---|
| wiki | 「暴击时…（**向下取整**）」 |
| 实际 | **银行家舍入**（.5 往偶数靠） |

**实际影响**：

| 算出 | wiki 说 | 实际 |
|---|---|---|
| 12.5 | 12 | 12 |
| **13.5** | **13** | **14** ← 差 1 |

**只有"奇数 + 0.5"这一种情况会差 1 点。** 平时不影响。

> 有意思的是，wiki 在**子弹分裂**那条写的是「向偶数取整」（这是对的），说明作者知道这个规则，只是**暴击那条忘了统一**。

### ② 暴击伤害跟武器等级有关（wiki 没写）

```asm
; ApplyPlayerCriticalToResolvedDamage
bl   #0x647861c        ; ResolveWeaponLevel(…) ← 先算武器等级
mov  w3, w0            ; 把等级结果传进主逻辑
```

**⟹ 同一种武器，等级不同暴击伤害可能不同。** wiki 完全没有提这一点。

## 五、一句话总结

1. **暴击是两步**：先掷骰子（暴击率），再乘倍率（暴击倍率）
2. **倍率是逐武器配置的**，不是全局 200%，代码里没有这个常数
3. **累加累乘规则就一句**：同类相加，异类相乘
4. **wiki 只有 2 处该改**：取整方式（差 1 点）、暴击×武器等级（漏了）
