```

密钥：全局单一（设备版与 zip 版 247/247 md5 相同）
```

**证据链**：
- ✅ 252/252 长度 %8 == 0

- ✅ PKCS7 padding 长度随明文变化

### 3.2 ★ 绕过方案（已实测）

```bash
# 属性层绕过（有效）
adb shell su 0 setprop init.svc.adbd stopped
adb shell su 0 setprop ro.debuggable 0
→ 游戏存活从 10 秒 → 150+ 秒
# ❗ 但挂 Frida 时 ACE 仍阻止 il2cpp 加载

# ★ 零 Frida 方案（完全成功）
adb shell su 0 dd if=/proc/$PID/maps of=/data/local/tmp/_m.txt
adb shell su 0 dd if=/proc/$PID/mem of=out.bin bs=1048576 skip=$((LO/1048576))
→ il2cpp 正常加载（531 MB），可读 4950 MB 内存
```
