# 护甲回复

## 函数对

| 函数 | 地址 | 作用 |
|---|---|---|
| `ArmorRestoreSpeed` | 0x079966E4 | 加速护甲回复 |
| `SlowDownArmorRestoreSpeed` | 0x079970BC | 减速护甲回复 |
| `ArmorRecoveryProbability` | 0x0833FF64 (fb 0x0833FFBC) | 概率型回复 |
| `RecoverArmorInShield` | 0x0981D9D8 | 护盾内回复 |
| `Skill1AddExtraArmor` | 0x097EF2D0 | 技能额外护甲 |

**⟹ 护甲回复 = 速度修正 + 概率触发（双机制）**
