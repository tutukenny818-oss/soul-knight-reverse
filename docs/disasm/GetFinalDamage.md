# GetFinalDamage（三层结构分界点）

**地址**：`0x067C2430`
**IFix fallback**：`0x067C23FC`

## 反汇编

```asm
0x067C2478  ldr  x0, [x19, #0x48]     ; 读「倍率对象」指针
0x067C247C  cbz  x0, #0x67c24f4       ; ★ 为空 → 整数路径
0x067C2484  bl   #0x724de94           ; get_Value(倍率对象)
0x067C24D0  bl   #0x6231a14           ; → libm round
0x067C24F4  ldr  w0, [x19, #0x3c]     ; ★ 整数路径：直取 [0x3C]
```

## 关键结论

wiki 说的「内部攻击力 → 外部攻击力 → 实际伤害」三层，
**代码分界点 = 字段 `[0x48]` 是否非空**。

| 字段 | 类型 | 含义 |
|---|---|---|
| `[0x3C]` | int32 | 基础伤害 |
| `[0x48]` | ptr | 倍率对象 |
| `[0x28]`（倍率对象内） | float32 | 倍率值 |
