# 参数槽位表（统一抽象）

游戏把「角色自身属性」抽象成**参数槽位**，天赋/装备只能改这些值。

| 槽位 | 用途 | 默认值 | 设置函数 |
|---|---|---|---|
| 3 | 冷却（副） | 0.02 | `SetBaseValue` |
| 5 | 冷却（备用） | 0.0 | `SetBaseValue` |
| 8 | 冷却（主） | 0.05 | `SetBaseValue` |
| 14 (0xE) | 自身攻速因子 | 30.0 | `GetPercentParam` |
| 15 (0xF) | 自身移速因子 | 15.0 | `GetPercentParam` |

## 统一读取函数

```c
float GetPercentParam(object* self, float default_value, int slot);
// @ 0x068BED28
```

调用方只需提供「默认值 + 槽位」。

## 默认值对比

| 链 | 默认值 | 说明 |
|---|---|---|
| 攻速 | 30.0 | 最高 —— 主要输出属性 |
| 移速 | 15.0 | 中等 |
| 冷却 | 0.05 / 0.02 | 最小 —— 加成敏感 |
