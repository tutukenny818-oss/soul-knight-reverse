# AddCriticFactor（暴击因子累加）

**地址**：`0x08308728`
**IFix fallback**：`0x08308770`

## 反汇编（只有 5 条指令）

```asm
0x08308770  ldr  s0, [x19, #0x68]    ; 读当前暴击因子
0x08308774  fadd s0, s0, s8          ; ★ 加上新因子（纯累加）
0x08308778  str  s0, [x19, #0x68]    ; 写回
0x0830877C  ret
```

## 关键结论

**暴击因子存在字段 `[0x68]`，多个来源逐个 `fadd` 累加** ——
与 wiki「同顺位加算」一致。
