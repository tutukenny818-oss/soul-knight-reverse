## 1. ★★★★★★ 完整技术路径（可复制）

### 1.1 五步链路

```
步骤 1：绕过 ACE 属性检测
   adb shell su 0 setprop init.svc.adbd stopped
   adb shell su 0 setprop ro.debuggable 0
   → 游戏存活从 10 秒提升到 150+ 秒

步骤 2：不挂 Frida，正常启动游戏
   adb shell su 0 monkey -p com.ChillyRoom.DungeonShooter \
       -c android.intent.category.LAUNCHER 1
   → il2cpp 正常加载（531 MB）★ 关键：挂 Frida 会被 ACE 阻止加载

步骤 3：读 maps 找关键段
   adb shell su 0 dd if=/proc/$PID/maps of=/data/local/tmp/_m.txt
   → 2669 个可读段 / 4950 MB
       anon 441 段 972 MB
       il2cpp 9 段 531 MB
       malloc 32 段 94 MB

步骤 4：dump 关键段
   adb shell su 0 dd if=/proc/$PID/mem of=... bs=1048576 skip=$((LO/1048576)) count=N
   → 39 段 / 597 MB

步骤 5：★★★ UTF-16LE 扫描（决定性）
   之前只扫 ASCII → 全空
   转 UTF-16LE → 整片 Lua 源码
```

### 1.2 ★ 为什么必须用 UTF-16LE

游戏把 Lua 源码以 **UTF-16LE** 形式存在内存里（`.NET string` 或 IL2CPP `Il2CppString`）。

**ASCII 侧搜 `TalentBase.create` / `local BuffBase` = 0 命中；UTF-16LE 侧一搜即中。**

## 4. ★★★ 密钥状态（明确结论）

### 4.1 已穷举的密钥池

| 池 | 规模 | 结果 |
|---|---|---|
| 常量派生 | 84 | ❌ |
| IFix 补丁 8 字节窗口 | 285,170 | ❌ |

| metadata 8 字符窗口 | 1,500,000+ | ❌ |
| **合计** | **1,018,065（去重后）** | **0 命中** |

### 4.2 结论

**密钥不在任何静态数据中。**

**原因**（已由反汇编确证）：
```
GameConfigManager::get_SecretKey @0x828747C (AOT 桩)
  mov w0,#0xBB5E ; movk w0,#1,lsl#16   → idx=0x1BB5E
  bl  0x95BFCD0   IsPatched(idx)
  b   0x9209140   __Gen_Wrap_215       ← 真实实现（IFix 运行时写入）
```
`__Gen_Wrap_215 @0x92258D0` **字节非法**（capstone 解析 0/8 条合法指令）⇒ 真实密钥派生**不在静态 .so 里**。
